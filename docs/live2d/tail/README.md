# Freigegebenes Ragdoll-Fell, V4

Eigenes generiertes Fellmaterial für den nativen Tororo-Schwanz, am 30.10.2026
vom Nutzer zur Verteilung freigegeben. `ragdoll-tail-atlas.png` ist der finale
Atlas (1254 × 1254, RGBA); `prompt.txt` dokumentiert die letzte Bildbearbeitung.
Er setzt die normalisierten UVs des privaten integrierten Modells voraus.

Nach Cubism-Export: `node tools/live2d/restore-tail-atlas.mjs <export> docs/live2d/tail/ragdoll-tail-atlas.png`.
Der Portrait-Restore bleibt zusätzlich erforderlich. Das Modell und die
Spenderquellen sowie der Cubism SDK bleiben im bestehenden privaten Paket.
